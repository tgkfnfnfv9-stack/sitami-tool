# 下見シート（株式会社小林機械）

機械の引取・購入前の「下見」内容をスマホで入力し、A4横の下見シートをPDFで出力・共有するためのツール。
立替精算書（tatekae）と同じ構成・デザインの単一HTMLファイル（`index.html`）です。

## 機能
- 入力：管理情報（高コン・下見日・担当・下見者）／依頼会社・現場／申請・手配／案件概要／機械（複数台、仕様・付属品・機械状態は別欄）／現場状況・搬出条件（チェック項目＋メモ）
- 下書きを自動保存（同じ端末・ブラウザで次回開いたときに復元）
- 「確認」で紙の下見シートと同じA4横の帳票をプレビュー。**記入しきれない分は自動で2枚目以降**に送られます（全ページ同じレイアウト・ページ数印字。現場状況は1枚目、入りきらない分は次ページに「続き」。1ページに入らないほど長い機械は、仕様などの行を分けて続きを次ページへ）
- 「出力」→ 共有（iPhoneの共有シート）／PDF保存
- 「保存」「読込」で入力データをJSONファイルとして保存・復元
- 「AI取込」：AIが作ったJSONを貼るだけで反映。初期設定は「追加・更新」（空の項目は消さずに足していく）、「置き換え」は確認のあと全部入れ替え（形式は [AI_SCHEMA.md](AI_SCHEMA.md)、`?ai=1` 付きURLで取込画面が開きます）
- ページ上で `window.SitamiTool.collect() / restore(data) / mergeData(data) / buildPages() / makePdf("sheet")` も呼べます（自動化用。写真関連の関数は停止中）

## 写真
**現在は一時停止中**：画面には「写真はLINEのアルバムに追加」とだけ表示しています。以下の仕組みはコードに残してあり（`PHOTO_ENABLED=false`）、運用方法を決めてから再開予定です。

- 撮影・選択時に自動で縮小（長辺1600px）して、この端末（IndexedDB）に保存。200枚程度でも扱えます
- 「追加する写真の札」（機械No.・種類）を先に選んでから撮ると、まとめて札が付きます。写真をタップで札・メモの変更、使う／使わない、削除
- 出力：下見シート／写真帳（A4横・1ページ6枚・番号と札入り）／シート＋写真帳
- AI用に書き出し：銘板・操作盤・手書きシートは1枚ずつ、それ以外は9枚を1枚にまとめ、1回分（5/10/20枚、初期値10枚）ずつに分割。各回の指示文をコピーでき、結果は「AI取込（追加・更新）」で統合
