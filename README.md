# 下見シート（株式会社小林機械）

機械の引取・購入前の「下見」内容をスマホで入力し、A4横の下見シートをPDFで出力・共有するためのツール。
立替精算書（tatekae）と同じ構成・デザインの単一HTMLファイル（`index.html`）です。

## 現状（UI試作）
- 入力画面：管理情報（高コン・下見日・担当・下見者）／依頼会社・現場／申請・手配／案件概要／機械（複数台）／現場状況・搬出条件／写真
- 「確認」で入力内容を紙の下見シートと同じレイアウトでプレビュー
- 保存・読込・PDF出力・AI取込・写真添付・自動下書き保存は **今後追加**（ボタンは「準備中」表示）

## AI取込（予定）
- 形式の草案は [AI_SCHEMA.md](AI_SCHEMA.md)
- `?ai=1` 付きURLで取込ダイアログが開きます
