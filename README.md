# 下見シート（株式会社小林機械）

機械の引取・購入前の「下見」内容をスマホで入力し、A4横の下見シートをPDFで出力・共有するためのツール。
立替精算書（tatekae）と同じ構成・デザインの単一HTMLファイル（`index.html`）です。

## 機能
- 入力：管理情報（高コン・下見日・担当・下見者）／依頼会社・現場／申請・手配／案件概要／機械（複数台、仕様・付属品・機械状態は別欄）／現場状況・搬出条件
- 下書きを自動保存（同じ端末・ブラウザで次回開いたときに復元）
- 「確認」で紙の下見シートと同じA4横の帳票をプレビュー。**記入しきれない分は自動で2枚目以降**に送られます
- 「出力」→ 共有（iPhoneの共有シート）／PDF保存
- 「保存」「読込」で入力データをJSONファイルとして保存・復元
- 「AI取込」：AIが作ったJSONを貼るだけで全欄に反映（形式は [AI_SCHEMA.md](AI_SCHEMA.md)、`?ai=1` 付きURLで取込画面が開きます）
- ページ上で `window.SitamiTool.collect() / restore(data) / makePdf()` も呼べます（自動化用）
